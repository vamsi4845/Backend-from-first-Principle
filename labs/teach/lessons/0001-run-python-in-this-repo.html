Lesson 1 — Run Python in the right folder

This matches your mission: be able to run lab commands without fighting the shell. You already know npm run dev; Python adds a virtualenv and slightly different paths.

Ideas (not commands yet)

  • Current directory matters. python exercises/values.py only works if that path exists from where you are standing in the terminal—same as node src/app.js.
  • venv is a folder of Python + installed packages for this project. After you activate it, python and pip point at the project, not a random install.
  • Git Bash uses source .venv/Scripts/activate, not backslashes, for activation.

Do this once (python-warmup)

cd /d/Grind/Backend-from-first-Principle/labs/python-warmup
source .venv/Scripts/activate
python -m pytest -q

Green output means “this folder’s Python + tests work.” If you are not in python-warmup, tests will not find the project layout.

Try one line

python -c "print('ok')"

You should see ok. That proves the active interpreter runs code.
