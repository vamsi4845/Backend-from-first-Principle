# Mission: Python + backend fundamentals for FastAPI work

## Why

You already ship backend features in Node.js. The new team uses **FastAPI**; you want the **same confidence** you had with Express—read a route file, run the server locally, change something, and know why it works—without feeling rushed past basics like shells, paths, and how Python files run.

## Success looks like

- Run **any** lab command from the repo and fix “wrong directory / wrong interpreter / wrong path” without guessing.
- Implement a small FastAPI change (new route or query param) and verify it with **browser docs + pytest**.
- Explain **one** HTTP idea (e.g. 404 vs 422) in your own words before moving to the next chapter.

## Constraints

- About **6–8 hours per week**, preferably in **one session at a time** with a single clear win (not a whole week of content).
- Prefer **Git Bash** on Windows; document `source .venv/Scripts/activate` instead of backslash activate.
- Prior **Node** experience; **not** prior Python confidence.

## Out of scope (for now)

- Full Python CS curriculum, data science stack, or “learn every stdlib module.”
- Production deployment, Kubernetes, or Kafka until the core API + tests path feels easy.
- Reading all 27 manual chapters in order without the weekly checklists.
