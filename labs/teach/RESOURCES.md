# Resources: Python + FastAPI + this repo

## Knowledge

- [Python 3 tutorial (official) — sections 1–5](https://docs.python.org/3/tutorial/index.html)  
  Use for: first syntax, imports, `if`/`for`, functions, modules. Stop before the tutorial sprawls into topics you do not need yet.

- [venv — Creation of virtual environments](https://docs.python.org/3/library/venv.html)  
  Use for: why `python -m venv .venv` exists and why activation matters (isolated packages).

- [pytest: get started](https://docs.pytest.org/en/stable/getting-started.html)  
  Use for: what `pytest -q` is doing in `labs/python-warmup`.

- [FastAPI docs — First steps](https://fastapi.tiangolo.com/tutorial/first-steps/)  
  Use for: mental model of `app`, routes, automatic OpenAPI at `/docs` when you reach `labs/task-api`.

- **This repo — chapters (local):** run `npm run dev` from the repository root, then read **HTTP & CORS** and **Routing** first. Use for: principles that match your job (status codes, method + path as a key).

## Wisdom (communities)

  Use for: quick “why does my path / venv fail?” questions when stuck.
