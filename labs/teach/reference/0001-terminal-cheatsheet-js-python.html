Terminal cheat sheet — Node vs Python (this repo)

Goal Node / npm Python (labs)
Project packages npm install → node_modules/ pip install -r requirements.txt → .venv/…
Activate environment (often none; or nvm use) source .venv/Scripts/activate (Git Bash)
Run one file node path/to/file.js python path/to/file.py
Run tests npm test / npx vitest python -m pytest -q
Run API server npm run dev uvicorn app.main:app --reload from labs/task-api

Path rule: If python exercises/values.py errors with “no such file,” check pwd (or cd) first.
