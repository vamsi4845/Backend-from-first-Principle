# Python warmup (lesson 0)

For **JavaScript/TypeScript** developers before `labs/task-api`. Goal: read and write the Python you will see in FastAPI—not become a Python expert.

```bash
cd labs/python-warmup
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
pytest -q
```

Work through [`../task-api/progress/00-python-from-javascript.md`](../task-api/progress/00-python-from-javascript.md) in order. Edit the `exercises/` files; tests tell you when each piece is correct.
